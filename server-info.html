Overview

This document outlines the design, implementation, and ongoing maintenance of a personal home server. The server is built on laptop hardware and utilizes Proxmox VE for virtualization. It hosts various services in Virtual Machines (VMs) and LXC containers, demonstrating practical knowledge of virtualization, containerization, networking, and system administration.

Hardware

Primary Hardware Node

  • Type: Laptop running Proxmox VE
  • CPU: Intel(R) Core(TM) i7-7500U @ 2.70GHz
  • Cores: 4 Cores
  • Memory: 16GB DDR4 RAM
  • Storage: 1TB Samsung SSD

Virtualization Platform

Proxmox VE

Type-1 Hypervisor managing all virtual machines and containers. Provides a robust web interface for cluster management, storage allocation, and network configuration.

Virtual Machines

Home Assistant OS

Centralized home automation platform managing smart devices, Zigbee networks, and automated routines.

Docker Host (Ubuntu)

Dedicated VM for containerized applications like Karakeep, providing a sandbox for service isolation and testing.

LXC Containers

  • Beszel: Real-time system monitoring and metrics dashboard.
  • Homepage: Modern, static dashboard for all internal services.
  • Pi-hole: DNS-level advertisement and tracker blocking.
  • Ntfy: Push notification gateway for server alerts and scripts.

Service Overview

Network Security: All services are strictly internal and connected via a Tailscale Mesh VPN for secure, zero-config remote access.
